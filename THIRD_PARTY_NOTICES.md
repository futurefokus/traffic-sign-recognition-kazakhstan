# Third party sources

The selected sign crops derive from TN02/Road-Signs-Dataset, a mixture of GTSRB, RTSD, and additional Baku photographs. Source README and license are retained in the release bundle. No claim of self-collected or Kazakhstan field data is made.

The standard DINOv2 ViT-S/14 architecture and pretrained weights are from Meta AI under Apache License 2.0. The matching code is bundled in the release at commit 7764ea0f912e53c92e82eb78a2a1631e92725fc8. See DINOv2_LICENSE and dinov2_source/LICENSE.

The Gradio interface and training scripts are project code. Python dependencies retain their own licenses.
